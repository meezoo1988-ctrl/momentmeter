# MomentMeter

خط إنتاج محلي مجاني لفيديوهات YouTube Shorts، مع حفظ ملفات المشروع وبيانات الإنتاج على GitHub.

**الحالة الحالية:** كود إنتاج جاهز للاختبار، ومسودة أول فيديو. لم تُربط قناة YouTube ولم يُنشر فيديو. المسودة تحتاج مقاطع مرخّصة ومراجعة النص ليتوافق مع الأحداث الحقيقية. التعليق الإنجليزي الافتراضي صوت محلي آلي؛ يمكن استبداله بتسجيل أصلي أفضل. لا توجد موسيقى أو API مدفوعة.

## التثبيت على Ubuntu

```bash
bash install.sh
python3 -m unittest discover -s tests -v
```

السكربت يثبت Python وFFmpeg وespeak-ng وGit والخطوط من مستودعات Ubuntu. يحتاج sudo واتصال إنترنت عند التثبيت فقط. الإنتاج اللاحق محلي.

## أول فيديو

1. افحص قناة Theory في YouTube Studio: المحتوى السابق، الجمهور النشط، المخالفات. سجّل القرار في `data/channel-audit.md` ثم حدّث `data/config.json`. هذا المشروع لا يصل إلى القناة تلقائيًا.
2. اختر خمسة مقاطع مناسبة من مصادر تسمح بالاستخدام، واقرأ الترخيص الخاص بكل مقطع. نزّلها يدويًا إلى `assets/01.mp4` … `assets/05.mp4`.
3. عدّل `data/jobs/first-short.json`: وصف وتعليق كل مشهد، رابط المصدر، رابط الترخيص، اسم الترخيص، و`rights_verified: true` بعد التحقق. ترتيب العرض 5 ثم 4 ثم 3 ثم 2 ثم 1. النص المرفق مثال لا يدّعي أنه يصف مقاطع تم اختيارها بالفعل.
4. عدّل `start` لاختيار بداية المشهد بالثواني. يمكن إضافة `voice_file` إلى كل مقطع لتسجيلك الشخصي؛ التسجيل الأول يشمل Hook. لا تنس مطابقة الترجمة مع التسجيل.
5. شغّل:

```bash
python3 momentmeter.py validate
python3 momentmeter.py render
```

ينتج `output/first-short/short.mp4` عموديًا 1080×1920 و30fps ومدته 25–40 ثانية. الصوت الأصلي للمقاطع يُستبعد، ويُستخدم التعليق فقط. العناوين تعرض الرتبة، والترجمة موزعة زمنيًا حسب طول المقطع؛ ليست محاذاة آلية لكل كلمة. يفشل الإنتاج عندما يكون المصدر أقصر من التعليق.

6. شاهد الفيديو كاملًا: تطابق الأحداث والتعليق، القص العمودي، وضوح الصوت والترجمة، الحقوق، وعدم وجود علامات مائية غير مسموحة. ثم:

```bash
python3 momentmeter.py approve
```

7. ارفع الفيديو يدويًا إلى YouTube Studio باستخدام النص الموجود في `output/first-short/upload.txt`. اختر إعداد الجمهور الصحيح. بعد النشر:

```bash
python3 momentmeter.py mark-published --url 'https://www.youtube.com/shorts/VIDEO_ID_11'
python3 momentmeter.py sync
```

استبدل المثال برابط الفيديو الحقيقي. أول إصدار لا يستخدم YouTube Data API أو OAuth ولا يرفع تلقائيًا. الموافقة تحفظ بصمة الفيديو والمدخلات؛ أي تغيير يحتاج إنتاجًا ومراجعة جديدة.

## حفظ الداتا على GitHub

أنشئ مستودعًا مستقلًا **Private** باسم `momentmeter`، ثم ارفع المشروع إلى جذر المستودع. من هذا المجلد:

```bash
git init -b main
git add .
git commit -m 'Initialize MomentMeter production pipeline'
git remote add origin https://github.com/meezoo1988-ctrl/momentmeter.git
git push -u origin main
```

استخدم مصادقة Git الرسمية؛ لا تكتب token داخل الرابط أو ملفات المشروع. إذا كان المستودع موجودًا وفيه ملفات، استنسخه أولًا وانقل الملفات إليه بدل الكتابة فوق تاريخه.

`data/` يخزن إعدادات القناة، نصوص الفيديو، ترتيب المشاهد، روابط المصادر والتراخيص، الموافقات وروابط النشر. أمر `sync` ينشئ commit ثم يدفع تغييرات `data/` فقط. GitHub يحفظ هذه البيانات مع تاريخ تغييراتها؛ FFmpeg يعمل على Ubuntu لديك. الفيديوهات الخام والنهائية لا تُرفع إلى Git، لذا احتفظ بنسخة احتياطية منها منفصلة. ملف `.gitignore` يستبعدها ويستبعد الأسرار. لا تضع معلومات سرية داخل `data/`.

GitHub Actions يتحقق من البيانات والاختبارات عند push. لا يُشغّل إنتاجًا دوريًا، ولا يشترك في خدمة مدفوعة، ولا يتجاوز موافقة النشر.

## Telegram الاختياري

```bash
export TELEGRAM_BOT_TOKEN='your-token'
export TELEGRAM_CHAT_ID='your-chat-id'
python3 momentmeter.py notify
```

يرسل إشعارًا نصيًا بأن فيديو المراجعة جاهز. **لا يرسل الفيديو نفسه ولا يستقبل الموافقة من Telegram** في هذا الإصدار. الموافقة محلية بالأمر `approve`. القيم تخص بيئة التشغيل ولا تُحفظ في Git.

## الإيقاع التشغيلي

فيديو واحد يوميًا عند توفر محتوى مناسب ومراجعة مكتملة. اختيار المقاطع وحقوقها، مطابقة النص، الموافقة والرفع يدويًا. المونتاج والتعليق المحلي والترجمة وتسجيل البيانات آليًا. لا يوجد جامع مقاطع أو توليد نصوص عبر خدمات خارجية في هذا الإصدار.
