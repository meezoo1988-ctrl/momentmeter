# MomentMeter

إنتاج YouTube Shorts على GitHub Actions؛ لا يحتاج Windows أو جهازًا يعمل طوال اليوم.

القناة: https://www.youtube.com/@MomentMeter-z1e

## التشغيل السحابي

Workflow **Produce a review Short** يثبت FFmpeg وespeak-ng، ينزّل مصادر Pexels
المسجلة في الفيديو الجاهز، وينتج تعليقًا إنجليزيًا وترجمة وترتيبًا عموديًا
1080×1920، بمدة 25–40 ثانية ومن دون موسيقى.

التشغيل اليومي الساعة 3 عصرًا بتوقيت الرياض، أو من Actions → Produce a review
Short → Run workflow. الحد فيديو جديد واحد في اليوم عند وجود مهمة جاهزة.
المهام في `data/jobs/`؛ `first-short` مثال مسودة، و`pets-001` أول مهمة حقيقية
بخمسة مصادر وتعليق أصلي. لا يوجد توليد لا نهائي للمحتوى؛ يلزم تجهيز مهام جديدة.

عند نجاح الإنتاج يظهر **review-pets-001** في Artifacts، ويحتوي الفيديو والنص
ومعلومات المراجعة. مدة الاحتفاظ 30 يومًا. بيانات التشغيل تحفظ في
`data/cloud-runs/` بعد حفظ الملف بنجاح، لمنع تكرار إنتاج المهمة.
المقاطع الخام والأسرار لا تحفظ في المستودع العام.

## Google Drive

كود رفع الفيديو إلى مجلد خاص جاهز، لكن يحتاج تفويض Google مستقل للتشغيل
على GitHub. ربط Drive مع ChatGPT وحده لا يمنح GitHub هذا التفويض.

في Settings → Secrets and variables → Actions، أضف الأسرار:

- `GOOGLE_CLIENT_ID`
- `GOOGLE_CLIENT_SECRET`
- `GOOGLE_REFRESH_TOKEN`

وأضف المتغير `DRIVE_FOLDER_ID`. لا تكتب القيم السرية في الكود أو المحادثة.
التفويض يستخدم حساب Google وDrive API بصلاحية `drive.file`، والمجلد يجب أن
يكون متاحًا للتطبيق. التفاصيل في [CLOUD.md](CLOUD.md).

دون ربط المجلد، يحفظ الفيديو في Artifacts. إذا ضبط المجلد وفشل التفويض، يفشل
التشغيل ويظهر الخطأ؛ لا يعلن نجاح حفظ غير حاصل.

## YouTube والمراجعة

هوية القناة وصورتها وغلافها ووصفها ضُبطت في YouTube Studio.
النشر الآلي لم يُربط بعد. تسجيل الدخول في المتصفح لا ينتقل إلى GitHub Actions،
وAPI key لا يكفي لرفع الفيديو. يلزم تفويض YouTube OAuth منفصل.

شاهد أول ملف كاملًا قبل النشر: جودة الصوت الاصطناعي، القص، وضوح الترجمة،
ومطابقة التعليق للمشاهد. ملفات المراجعة لا تعتبر فيديوهات منشورة.
يمكن رفع الملف من YouTube Studio بالنص الموجود في `upload.txt`.

## التطوير والتشغيل المحلي الاختياري

```bash
bash install.sh
python3 -m unittest discover -s tests -v
python3 momentmeter.py validate --job pets-001 --draft
python3 cloud.py produce
```

أدوات Windows القديمة متاحة كخيار، لكنها ليست جزءًا مطلوبًا للتشغيل السحابي.
الأوامر المحلية `approve` و`mark-published` و`sync` تحفظ الموافقة وبصمة الملف
ورابط النشر. Telegram الموجود حاليًا يرسل إشعارًا نصيًا فقط؛ ليس نظام موافقات.

## الحالة

الكود السحابي والمهمة الأولى رُفعا، والاختبارات نجحت محليًا وعلى GitHub.
نتيجة إنتاج الفيديو الحقيقي يجب التحقق منها في Actions؛ نجاح الاختبارات وحده
لا يعني نجاح التنزيل أو المونتاج. التخزين في Drive والنشر الآلي على YouTube
لم يُفعّلا قبل إكمال تفويض حساب Google.
